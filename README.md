# 電路好好玩

適合國小五年級的互動式自然科學教材。學生化身「亮光工程師」，從完成簡單通路開始，分別比較燈泡串聯、燈泡並聯、電池串聯與電池並聯，再將概念應用到家中燈具、延長線、斷路器與安全用電。

## 適用對象與時間

- 對象：國小五年級
- 科目：自然科學
- 建議時間：40 分鐘
- 語言：繁體中文

## 學習目標

1. 說明燈泡發亮需要電源、正確接點與完整通路。
2. 從接點、路徑、亮度與故障現象，分辨燈泡及電池的串聯、並聯。
3. 運用電路概念判斷生活用電與安全情境。

## 教材特色

- 七個頁籤，每次聚焦一個主要學習任務。
- 四張獨立 SVG 電路圖，分別呈現燈泡與電池的串聯、並聯，附分階段動畫控制。
- 開關觀察、條件切換、故障模擬、預測與驗證等互動。
- 6 則有獨立圖解的生活應用。
- 10 題生活情境、現象判讀與安全推理題，附即時解釋。
- 本機保存學習進度與最佳測驗成績。
- 支援鍵盤、觸控、手機與降低動畫偏好。

## 頁籤內容

1. 學習任務
2. 讓燈泡亮
3. 串聯與並聯
4. 互動實驗
5. 生活中的電
6. 闖關挑戰
7. 自主學習

## 使用方式

可直接開啟建置後的網站，依序操作頁籤；教師也可搭配 [教師使用說明](./docs/lesson-plan.md) 進行全班討論。實體操作僅使用乾電池與低電壓燈泡，不可操作插座或拆解家電。

## 本機啟動

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
```

## 專案結構

- `index.html`：頁籤教材與 SVG 圖解
- `css/`：視覺、動畫與響應式樣式
- `js/`：導覽、互動、測驗與進度
- `data/`：內容、題庫、資源與課綱資料
- `docs/`：教案、設計、來源與測試報告

## 使用技術

HTML5、CSS3、SVG、原生 JavaScript、JSON、Vite。

## 課綱對應

內容對應自然科學領域學習內容 `INe-Ⅱ-9`：「電池或燈泡可以有串聯和並聯的接法，不同的接法會產生不同的效果」，並培養系統思考、問題解決與安全判斷。
