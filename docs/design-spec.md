# 教材設計規格

## 學習契約

- 主題：簡單電路、通路與斷路、燈泡／電池的串聯與並聯、安全用電。
- 對象：國小四年級自然科學。
- 先備知識：知道乾電池有正、負極，能辨認燈泡金屬接點，具備基本滑鼠、觸控或鍵盤操作能力。
- 使用情境：40 分鐘課堂引導、兩人合作操作或課後自主複習。
- 核心目標：用完整路徑解釋燈泡是否發亮；從接點與支路分辨四種接法；用故障現象與安全規則解決生活問題。
- 成功表現：學生能指出路徑缺口、分辨同一路／不同支路、預測移除元件的結果，並說出支持答案的觀察證據。

## 目標與證據矩陣

| 學習目標 | 畫面／互動 | 學生行動 | 正確性依據 | 成功證據 |
|---|---|---|---|---|
| 說明燈泡發亮條件 | 開關與完整通路 SVG | 切換開關，比較電流點與亮度 | 完整閉合路徑、燈泡兩接點分接電池兩端 | 能指出缺口消失後燈泡才亮 |
| 分辨燈泡串、並聯 | 四接法比較與移除元件 | 切換接法、播放步驟、拿掉第 2 顆燈泡 | 串聯單一路徑；並聯有獨立支路 | 能用「同一路／不同支路」解釋故障結果 |
| 分辨電池串、並聯 | 電池接點圖與效果文字 | 比較正負極接點與燈泡亮度／使用時間 | 串聯正接負；並聯正接正、負接負 | 能辨認接點並說出兩種效果差異 |
| 從故障提出推論 | 預測與驗證實驗 | 先選預測，再驗證正常、串聯故障、並聯故障 | 通路是否仍完整 | 預測後能指出故障位置與仍存在的支路 |
| 遷移到安全情境 | 六張生活應用卡與十題闖關 | 先回答問題，再揭示觀察證據 | 教育部教材與台電安全指引 | 能解釋並聯家電、延長線負載與潮濕風險 |

## 常見迷思與處理

- 只接電池正極就會亮：以開關示範強調必須回到另一端形成完整通路。
- 串聯、並聯只看元件排成一列或兩列：改以「電流有一條路或多條支路」判定。
- 並聯插孔數多就能無限增加負載：生活卡以額定總容量和過熱風險修正。
- 一顆燈泡故障，另一顆一定熄滅：故障實驗分別驗證串聯與並聯。
- 乾電池實驗和家用插座一樣安全：教材明確限制只用乾電池與低電壓燈泡，市電情境只做判斷、不實作。

## 視覺與互動原則

教材採七頁籤單一任務畫面、原生 SVG 教學圖解、觸控友善控制與本機進度保存。深藍表示導線與結構，暖黃表示發亮，珊瑚紅表示電流點、故障或危險，薄荷綠表示成功與安全。移動電流點必須保持在導線路徑內；手機版不依賴 SVG 內的小字理解；所有狀態同時用文字、形狀或標記呈現，不只靠顏色。
