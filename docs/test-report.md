## 實際操作與視覺證據

桌機 1440×1000：

1. 學習任務：確認導線分別接到燈泡側邊金屬殼與底部接點，紅色箭頭由正極經燈泡回到負極。
2. 讓燈泡亮：閉合開關後，開關、傳統電流箭頭、燈泡與文字同步更新。
3. 串聯與並聯：切換四種模式，確認沒有大型箭頭；小紅色光點沿正極到負極方向流動，並測試播放／暫停／慢速／重播、移除元件與恢復。
4. 互動實驗：驗證正常、串聯故障與並聯故障三個邊界結果。
5. 生活應用：檢查六張照片的真實結構與 16:9 裁切，並揭示每張卡片的照片重點與概念解答。
6. 闖關挑戰：作答、鎖定、正誤樣式、解釋、下一題與回看教材。
7. 自主學習：來源、年級、摘要、查核日期與外部連結均可見。

平板 768×1024 與手機 390×844：

- 七頁籤、四接法、故障實驗、生活卡、測驗與資源逐頁檢查。
