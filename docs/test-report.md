## 尚有限制

- 教材以國小階段的定性比較呈現亮度與使用時間，沒有模擬燈泡電阻、電池內阻、實際電壓或電流數值；文字因此使用「通常」與「接近」避免暗示固定量值。
- 自主學習資源位於外部網站，日後仍可能改址或下架，需定期重查。
- 本報告先記錄本機建置與瀏覽器結果；公開 GitHub Pages 驗證會在部署完成後補記。
